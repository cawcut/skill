# Choose a voice-over voice

Use the script's language, or the conversation language if the user has yet to supply the script. Filter the catalog by `languages` and show each `voice_id` once. An empty catalog means voices are unavailable. If only the language filter is empty, ask which other language to browse.

Show up to eight voices at a time. When the user describes a tone or use, compare `summary`, `when_to_use`, `when_not_to_use` and `tags` to the brief. On MCP, pass a short English keyword as `voice_query` if the tool advertises it. Broaden or remove the query if it returns no matches. On CLI, shortlist from the returned voices. Show the best fits first and mention a relevant tradeoff. For an open-ended request, put voices with a sample in the selected language first, then `recent_voice_ids` in their listed order, then catalog order. Mark previously used voices and offer “More voices” when available.

Before asking for a pick or for the missing script, send a Voice | Traits | Listen table in a normal chat message in the user's language. Describe each voice using its summary and relevant catalog traits. On older servers use the supplied name, gender and age. Copy each `previews[].preview_audio_url` verbatim into its Listen cell, including the signed query string. On MCP, each native audio resource link on the page also carries the exact URI. If the host saved a large tool result to a file, read the selected entries from that file before linking them. Localize the link label, e.g. “▶ 试听”. Prefer a sample whose `language_code` matches. Otherwise link the first available sample and name its language in the label. For a voice without a sample, write “no preview” in the user's language.

Tell the user that auditioning the samples is free. Ask for the voice by name, using plain-text options in the question tool or a numbered choice in chat. Recommend the best fit for a stated brief. Without a style preference, recommend the most recently used match with a sample in the selected language, otherwise the first voice shown. Collect any missing script and wait for the choice before creating or editing a TTS node with the selected catalog `voice_id`.
